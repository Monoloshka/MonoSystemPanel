# MonoSystemPanel

**Mono** (Monoloshka) · **System** (управление системой устройств) · **Panel** (графический интерфейс)

Приложение для Linux, Windows и Android. Подключается к серверу или роутеру по SSH и рисует интерфейс
(кнопки, поля, полосы, таблицы служб) по простому текстовому описанию (YAML). Программировать не нужно.
Справка по формату описания есть внутри приложения.

A cross-platform app (Linux, Windows, Android) that connects to a server or router over SSH and builds
its UI (buttons, fields, progress bars, service tables) from a simple YAML description. No coding needed.
Format help is built into the app.

## Возможности
- Избранные серверы (имя, хост, порт, пользователь, DNS). Пароли нигде не сохраняются.
- Проверка отпечатка ключа сервера, IPv4 и IPv6 (в том числе адреса Yggdrasil и Mycelium), свой DNS необязателен.
- Страницы из YAML: поля, кнопки, цепочки команд с запасными вариантами, полосы, таблицы из вывода команд.
- Кнопки и страницы показываются, только если нужные команды есть на устройстве.
- Список служб OpenWrt целиком описан в примере конфигурации: автозапуск, старт, перезапуск, стоп, CPU, RAM, PID.
- Кнопка перезагрузки: приложение само ждёт устройство и переподключается.
- Языки из файлов `src/lang/*.json` (можно добавить свой), светлая и тёмная тема по настройкам системы.

## Как получить установщики
1. Загрузите все файлы в репозиторий GitHub (ветка main). Папка `.github` скрытая, не потеряйте её.
2. Вкладка Actions, «Сборка», Run workflow.
3. Скачайте файлы из Artifacts: `linux-deb-appimage` (`.deb`, `.AppImage`), `linux-flatpak`, `windows-exe`, `android-apk`.
4. Дополнительные форматы (`.msi`, `.rpm`, Linux ARM64, macOS, Android для всех процессоров) собираются отдельно
   вручную: Actions → «Дополнительные форматы (не проверены)» → Run workflow. Автор их не проверяет.

## Системные требования
Windows 10 и новее (нужен WebView2), Linux с WebKitGTK 4.1 (Ubuntu 22.04, Linux Mint 21 и новее), Android 7 и новее.

## Реклама
В приложение встроены рекламные баннеры (папка `src/ads`, список в `src/ads.js`). Они лежат внутри
программы, не загружаются из интернета, подписаны словом «Реклама» и ничего не отслеживают.
Долгое нажатие на баннер копирует его ссылку. В YAML-описаниях баннеры изменить нельзя.
Проект открытый (MIT): форк может убрать баннеры.
